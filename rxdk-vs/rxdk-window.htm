The RXDK window

← Overview

Open it from the menu bar: RXDK > RXDK Window. It is the hub for everything around the build — build, deploy and debug themselves are native Visual Studio (F5, right-click Build, the green button). The window groups its actions:

Xbox console

  • Set… — set the devkit IP address or hostname (shown next to it).
  • Warm Reboot Xbox — warm-reboot the console.

Project

  • New Project… — opens File > New Project (filter by Xbox).

Folders

  • Open SDK Folder — the staged headers/libs.
  • Open Host Tools Folder — the host tools.
  • Open Documentation Folder — the cloned docs.

Documentation

  • Xbox SDK Documentation — the Xbox SDK API reference.
  • Extension Documentation — this documentation.

Tools

  • Launch xbWatson — the debug-output monitor.
  • Xbox Neighborhood (App) — the standalone Xbox Neighborhood application.
  • Xbox Neighborhood (Explorer) — the Xbox Neighborhood shell folder.
  • Cycle Globals Visibility — during a debug session, cycles the Globals scope (Title / +Constants / All).

Setup

  • Install Prerequisites — installs any missing components (Zig, host tools, SDK, docs); reports when everything is already present.
  • Fetch Latest RXDK-SDK — update an already-installed SDK.
  • Install .NET 8 Runtime — the runtime the build engine needs.
  • Settings — open Tools > Options.
  • Refresh — re-query the devkit address.
