Getting started

← Overview

1. Install prerequisites

After installing the RXDK VSIX, open the RXDK tool window (RXDK > RXDK Window on the menu bar) and click Install Prerequisites. This downloads only what is missing — the clean-room Zig toolchain, the host tools, the RXDK-SDK (headers + libs), and this documentation — into C:\ProgramData\RXDK. It is safe to re-run; it will report when everything is already present. It also installs the .NET 8 runtime the build engine needs (or use Install .NET 8 Runtime separately).

2. Point RXDK at your devkit

In the RXDK window, next to Xbox console, click Set… and enter your devkit's IP address or hostname. This is stored where the host tools look for it, so build/deploy/debug all use it. Warm Reboot Xbox reboots the console.

3. Create a project

File > New > Project, filter by the Xbox platform, and pick a template (for example Original Xbox Game for a spinning Direct3D 8 triangle). See Project templates for the full list. The new project has no rxdk.project.json — everything is configured through the project's property pages.

4. Build

Build normally: Build > Build Solution (Ctrl+Shift+B), or right-click the project > Build. The RXDK engine compiles your sources with Zig, links against the SDK libraries, produces the .xbe, and packs an .iso. Output goes to out\<Configuration>\ (e.g. out\Debug\), so Debug and Release don't overwrite each other. Errors and warnings appear in the Error List and the RXDK Output pane.

5. Deploy & debug (F5)

Press F5 (or the green Xbox Debugger (RXDK) button). RXDK builds, deploys the title and its media to the console, launches it, and attaches a source-level debugger over xbdm — breakpoints, call stack, Locals, Watch, and registers all work. See Deploy & debug for details.

If the devkit was off when you pressed F5, fix it and use the project's right-click Deploy to Xbox to retry the deploy without a full rebuild.

Build, deploy and debug are native VS

There is no separate RXDK "build" or "run" command — use the standard VS gestures (Build menu, F5, right-click the project). The RXDK window is for everything around that: the console, folders, documentation, host tools, and setup.
