RXDK for Visual Studio

Documentation for the RXDK Visual Studio extension — creating, building, deploying, running, and debugging original Xbox titles from Visual Studio 2022 / 2026. For the Xbox SDK API reference (Direct3D 8, XAPI, DirectSound, …) use Xbox SDK Documentation instead; that is a separate reference set.

(Using VS Code instead? See the RXDK VS Code extension docs.)

How it works

RXDK projects are native Visual Studio C++ projects (.vcxproj) of the Makefile configuration type. Visual Studio owns the IDE experience — Solution Explorer, IntelliSense, the Build menu, the Error List, and F5 — while the actual compile is delegated to the RXDK clean-room Zig toolchain against RXDK's own headers and libraries (the retail compiler cannot link them, so it only powers the IDE). You never edit a rxdk.project.json: the .vcxproj is the single source of truth, and the build settings live on the RXDK property pages.

Where things live

RXDK keeps shared data outside your project, in a per-user data root, so multiple projects reuse one copy. On Windows (VS is Windows-only) this is %ProgramData%\RXDK (e.g. C:\ProgramData\RXDK):

SubfolderContents
sdk/RXDK-SDK include + lib (headers and import/static libs).
tools/Host tools: imagebld, xdvdfs, xbcp, xbdel, xbneighborhood, xboxdbg-bridge, xbwatson, xbox-launch.
engine/Rxdk.Cli.exe / Rxdk.Dap.exe — the build/deploy engine and the debug adapter the extension drives.
docs/The RXDK-Docs repo clone: xboxsdk/ (API reference), rxdk-vs/ (this documentation), and rxdk-vscode/ (the VS Code docs).

These are populated by RXDK > RXDK Window > Install Prerequisites, which only downloads what is missing.
