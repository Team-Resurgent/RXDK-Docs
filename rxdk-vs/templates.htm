Project templates

← Overview

In File > New > Project, filter by the Xbox platform to see the RXDK templates. All build with the clean-room Zig toolchain and are ready to F5-debug on a devkit.

Multi-project templates

These create a solution with two projects — an executable plus a static library it references:

TemplateWhat it is
Original Xbox Cube (Multi-Project)A spinning textured cube whose geometry comes from a cubemesh library project.
Original Xbox Music Visualizer (Multi-Project)A D3D8 FFT equalizer that streams an Ogg Vorbis track through a vorbis decoder library project.

The executable references the library natively (Solution Explorer > References); RXDK builds the library first and links it automatically. See Library projects & references.

What a new project contains

A generated project keeps its build inputs in Solution Explorer folders:

  • src — your source files.
  • media (where applicable) — runtime assets deployed alongside the XBE.
  • RXDK — the shared build files (Rxdk.Xbox.props/.targets) and the property-page rule files. You normally don't edit these; use the property pages instead.
