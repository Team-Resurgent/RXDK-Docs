Property pages

← Overview

Right-click the project > Properties. Under Configuration Properties the RXDK pages appear together: Xbox Build, Xbox Image, Xbox Certificate, Xbox Title Info and Xbox Deployment. All settings are per-configuration.

Xbox Build

Compile/build settings — what the RXDK engine passes to the Zig toolchain.

SettingMeaning
Build FlavorDebug or Release (see Configurations).
Release OptimizationReleaseFast / ReleaseSafe / ReleaseSmall for Release-flavored configs.
Preprocessor DefinitionsExtra macros, on top of the built-in _XBOX;XBOX.
Additional / Public Include DirectoriesExtra include search dirs (also fed to IntelliSense).
LibrariesSDK libraries linked by name; libkernel is forced last automatically.
Additional Library DirectoriesExtra dirs to resolve Libraries names from (see Libraries).
Additional DependenciesExplicit prebuilt .lib files linked by path.
Pre-Build / Post-Build EventCommands run around the build (MSBuild macros allowed).

All path fields accept MSBuild macros such as $(ProjectDir), $(Configuration), $(MSBuildProjectDirectory).

Xbox Certificate

XBE certificate fields (imagebld /TEST*): Title ID, Alternate ID, Xbox Game Region, Xbox Game Rating, Media Types, LAN Key, Sign Key. Leave blank to omit the switch.

Xbox Title Info

Title Name, XBE Version, and the Title Info / Title Image / Save Game Image files (/TESTNAME, /TESTVERSION, /TITLEINFO, /TITLEIMAGE, /DEFAULTSAVEIMAGE). Image/file paths are project-relative.

Xbox Deployment

How media is collected and whether a disc image is produced:

SettingMeaning
Deployed FilesFiles/dirs staged next to default.xbe (into the ISO and copied to the console on deploy) — e.g. media.
Embedded FilesFiles baked into the XBE via imagebld /INSERTFILE, as source|section (e.g. media\dsstdfx.bin|dsstdfx).
Create ISO ImagePack an .iso with xdvdfs, or stop at the .xbe.
